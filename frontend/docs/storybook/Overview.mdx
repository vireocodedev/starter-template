# Application Storybook

This Storybook documents the application-owned UI and workflows built on Vireo Starter.

- **APPLICATION** demonstrates shell-level compositions and reusable application chrome.
- **FEATURES** demonstrates reusable business capabilities with deterministic data.
- **PAGES** demonstrates route compositions without requiring a live backend.

Stories are executable examples and interaction-test surfaces. Pure transformations and edge cases remain unit tests; complete user journeys remain Playwright tests.
